# 🚀 Hızlı Domain Transfer - worfe.vip

## ⚡ 2 Adımda Çözüm

### 1️⃣ Eski Siteden Domain'i Kaldır (2 dakika)

**Direkt link:** https://app.netlify.com/sites/worfe/configuration/domains

1. Link'e tıkla (yukarıdaki)
2. `worfe.vip` domain'ini bul
3. Domain'in yanındaki **"..."** (üç nokta) menüsüne tıkla
4. **"Remove domain"** veya **"Delete"** seçeneğini tıkla
5. Onayla

### 2️⃣ Yeni Sitede Domain Ekle (1 dakika)

**Direkt link:** https://app.netlify.com/sites/worfe-vip/configuration/domains

1. Link'e tıkla (yukarıdaki)
2. **"Add custom domain"** butonuna tıkla
3. Domain: `worfe.vip` yaz
4. **"Verify"** butonuna tıkla
5. DNS ayarları zaten yapılmış olduğu için otomatik doğrulanacak

## ✅ Tamamlandı!

Domain transfer edildi. Birkaç dakika içinde:
- ✅ Site erişilebilir olacak: https://worfe.vip
- ✅ SSL sertifikası otomatik aktif olacak (birkaç saat)

- **Eski Site (Domain Kaldır):** https://app.netlify.com/sites/worfe/configuration/domains
- **Yeni Site (Domain Ekle):** https://app.netlify.com/sites/worfe-vip/configuration/domains

## ⚠️ Not

DNS ayarları zaten Porkbun'da yapılmış olduğu için, sadece Netlify'da domain'i transfer etmek yeterli. DNS kayıtlarını değiştirmeye gerek yok!
